## Featured Projects

### [Multi-Site IaaS Provider Infrastructure](https://github.com/Mothrxa/Multi-Site-IaaS-Provider-Infrastructure)
Two-site network for a fictional cloud provider: HQ campus and a 2-spine / 4-leaf datacenter fabric joined by IPsec VPN over multi-area OSPF. Core services (DNS, DHCP, AAA, mail, monitoring, logging), Ansible-driven device config, and Terraform self-service provisioning of KVM VMs and Docker containers.

### [Distributed Online Voting Platform](https://github.com/Mothrxa/Distributed-Voting)
12-VM three-tier system with no single point of failure. HAProxy at every tier, stateless Node.js backend, and a PostgreSQL + Patroni + etcd cluster with automatic leader election. Validated by killing nodes mid-operation.

### [Homelab](https://github.com/Mothrxa/Homelab)
Self-hosted services on a Raspberry Pi 4 and a Fedora server, built to run unattended while I'm abroad. Pi-hole DNS/DHCP with router fallback, Wake-on-LAN relay for the sleeping server, Dockge and Uptime Kuma, all reachable over Tailscale.
